📝 Sobre el proyecto

Desarrollé una base de datos relacional en MySQL para un refugio de animales. El sistema permite organizar de forma integral y centralizada los ingresos, las fichas médicas (historia clínica y vacunación) y el registro seguro de las familias adoptantes. Además, incluye un modelo de análisis visual (Dashboard en Power BI) para la toma de decisiones.

🗂️ Qué incluye este repositorio

Documentación Final: Un archivo PDF con el modelo de negocio, Diagrama de Entidad-Relación (DER), diccionario de datos y conclusiones analíticas.

Scripts SQL: Todo el código necesario para crear la base de datos y sus objetos desde cero.

Backup de la Base de Datos: Un archivo de respaldo completo para restaurar el proyecto con toda su estructura y registros.

🚀 Cómo hacerlo funcionar

Ejecutar los scripts en el siguiente orden:

1) Tablas_y_datos_BUSTILLO.sql: Crea la estructura completa (tablas y relaciones) e inserta los datos iniciales para hacer pruebas.

2) Objetos_BUSTILLO.sql: Agrega todas las automatizaciones y herramientas de gestión (Vistas para reportes, Funciones, Procedimientos Almacenados y Triggers de seguridad).
