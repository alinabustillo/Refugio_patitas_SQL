📝 Sobre el proyecto

Armé una base de datos para un refugio de animales que ayuda a organizar de forma prolija los rescates, las fichas médicas de cada mascota y el registro de las personas que adoptan

🚀 Cómo hacerlo funcionar
1) Tablas_y_datos_BUSTILLO.sql: Crea todas las tablas y carga la información inicial.
2) Objetos_BUSTILLO.sql: Activa las funciones, vistas, procedimientos y triggers.
