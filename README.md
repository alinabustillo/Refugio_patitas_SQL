📝 Sobre el proyecto
Proyecto final para el curso de SQL. Desarrollé una base de datos relacional en MySQL para un refugio de animales. El sistema permite organizar de forma integral y centralizada los ingresos, las fichas médicas (historia clínica y vacunación) y el registro seguro de las familias adoptantes. Además, incluye un modelo de análisis visual (Dashboard en Power BI) para la toma de decisiones.

🗂️ Qué incluye este repositorio
Documentación Final: Un archivo PDF con el modelo de negocio, Diagrama de Entidad-Relación (DER), diccionario de datos y conclusiones analíticas.

Scripts SQL: Todo el código necesario para replicar la base de datos desde cero.

🚀 Cómo hacerlo funcionar
Para probar el proyecto, abrí tu motor de base de datos (ej: MySQL Workbench) y ejecutá los scripts en el siguiente orden:

Tablas_y_datos_BUSTILLO.sql: Crea la estructura completa del esquema (tablas y relaciones) e inserta los datos iniciales para hacer pruebas.

Objetos_BUSTILLO.sql: Activa toda la inteligencia del refugio (Vistas de reportes, Funciones de cálculo, Procedimientos Almacenados transaccionales y Triggers de seguridad).
